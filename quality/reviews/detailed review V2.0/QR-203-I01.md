## 1. Review Scope

This review evaluates Chapter 3 — How Artificial Intelligence Works (V2.0) to determine whether its content is accurate, complete, sufficiently developed, and suitable for beginner learners.

The review focuses on:

* Technical accuracy of AI concepts and explanations.
* Completeness and depth of the main topics.
* Logical progression from basic concepts to more advanced explanations.
* Clarity of explanations for beginner learners.
* Quality and relevance of worked examples.
* Practical learning activities and answer explanations.
* Visual support and learning resources.
* Consistency with other chapters.
* Alignment with the lecturer's Stage 2 requirements.

Particular attention is given to whether the chapter explains how AI works as a connected process, rather than presenting individual concepts without sufficiently explaining their relationships.

The chapter covers data, algorithms, models, machine learning, neural networks, deep learning, large language models, training, inference, evaluation, AI workflows, prompting, and practical activities.

## 3. Review Findings and Suggested Improvements

### QR-203-I01 — Findings and Suggested Improvements

**Finding 1: The connection between the main AI learning processes needs further development.**

The chapter explains data, algorithms, models, machine learning, training, evaluation, and inference. However, learners may still understand these as separate concepts rather than parts of one connected process.

**Suggested Improvement:**

Add a connected explanation showing how an AI system progresses through the main stages:

Data Collection → Data Preparation → Model Training → Evaluation → Inference → Monitoring.

Explain briefly what happens at each stage and how the output of one stage supports the next.

**Finding 2: The explanation of model training needs stronger connections between technical concepts.**

Parameters, loss, backpropagation, gradient descent, batches, and epochs are introduced, but their relationships could be clearer for beginners.

**Suggested Improvement:**

Use one simple training example to demonstrate how these concepts work together:

* The model makes a prediction.
* The loss function measures the prediction error.
* Backpropagation calculates how the parameters contributed to the error.
* Gradient descent updates the parameters.
* Repeated training helps the model improve its predictions.

The explanation should show the overall relationship instead of treating each term as an isolated definition.

**Finding 3: A complete practical example connecting the chapter's concepts is recommended.**

The chapter contains several examples and activities, but learners would benefit from following one AI application from its initial data to its final prediction.

**Suggested Improvement:**

Introduce an integrated example using a simple spam detection system:

1. Collect examples of spam and non-spam emails.
2. Prepare the data for the model.
3. Train the model using labelled examples.
4. Calculate prediction errors.
5. Improve the model through optimization.
6. Evaluate the model using unseen data.
7. Use the trained model to classify new emails.
8. Monitor its performance after deployment.

This example would connect data preparation, machine learning, model training, evaluation, and inference in one understandable scenario.

**Finding 4: The relationship between training, evaluation, and inference should be emphasized.**

These three concepts are important to understanding how AI systems operate, but their differences and sequence should be especially clear.

**Suggested Improvement:**

Add a simple comparison:

| Process    | Main Purpose        | What Happens                                                   |
| ---------- | ------------------- | -------------------------------------------------------------- |
| Training   | Learn patterns      | The model adjusts its parameters using training data.          |
| Evaluation | Measure performance | The model is tested using data that was not used for training. |
| Inference  | Produce predictions | The trained model processes new inputs and generates outputs.  |

Include a short example showing how the same model moves from training to testing and then to real-world use.

**Finding 5: Some practical applications could be developed further.**

The chapter contains useful examples and activities, but some explanations could connect the technical concepts more directly to real-world AI applications.

**Suggested Improvement:**

Add short application-based explanations where appropriate. For example:

* Image recognition: Explain how image data becomes an input for a trained model.
* Recommendation systems: Show how user behaviour can become useful features.
* Language models: Connect tokens, embeddings, and next-token prediction to the generation of text.

These additions should remain within the chapter's scope and avoid repeating material already explained in detail elsewhere.

**Finding 6: The dataset split explanation needs clarification.**

The chapter provides percentage ranges for training, validation, and test datasets. However, beginners may interpret these ranges as percentages that can be selected independently.

**Suggested Improvement:**

Clarify that the selected percentages must add up to 100%.

Include one clear example:

* Training: 70%
* Validation: 15%
* Testing: 15%

Explain briefly why each dataset has a different purpose.

**Finding 7: The estimated study time should be reviewed.**

The chapter contains 18 sections, 14 practice questions, and 4 hands-on activities. The current estimated study time of 100 minutes may be insufficient if learners are expected to complete all activities.

**Suggested Improvement:**

Review the estimated time based on the actual reading, practice, and hands-on activity requirements. Consider providing separate estimates for reading and completing the activities.

**Finding 8: Visual explanations should be strengthened for important processes.**

Visual support is important because the chapter introduces several processes that may be difficult for beginners to imagine through text alone.

**Suggested Improvement:**

Prioritize clear diagrams for:

* The overall AI development and learning process.
* The model training and optimization process.
* The difference between training, evaluation, and inference.
* The relationship between input data, model processing, and output predictions.

Ensure that all image files exist and that their Markdown paths work correctly on GitHub.

**Finding 9: The hands-on activity instructions should be verified.**

The chapter includes a Teachable Machine activity. This is useful because learners can experience a practical machine-learning workflow.

**Suggested Improvement:**

Test the current activity instructions and interface. Confirm that beginners can follow the steps, train a model, test it with new examples, and understand the results.

The activity should also explain what learners are expected to observe and learn from the experiment.

**Finding 10: References and external links require final verification.**

The chapter includes references to AI concepts, research, and practical learning resources.

**Suggested Improvement:**

Check that:

* Every cited source appears in the reference list.
* Bibliographic details are accurate.
* External links work.
* Online resources remain accessible.
* Claims based on research are represented accurately.

The references have not been independently verified during this review.

**Finding 11: Learner testing evidence is not included in the supplied material.**

The chapter contains explanations and activities, but the supplied material does not demonstrate that someone other than the author has followed the chapter as a learner.

**Suggested Improvement:**

Ask a teammate who did not write Chapter 3 to follow the material.

Record:

* What the learner understood.
* Which explanations were confusing.
* Which activities were difficult to complete.
* What revisions were made after receiving feedback.

This is important for demonstrating that the material is understandable to its intended beginner audience.

Overall, Chapter 3 provides a strong foundation for understanding how artificial intelligence works.

## 6. Feedback Communication

The following feedback should be communicated to the Chapter 3 author:

Chapter 3 already has strong content coverage, a logical structure, and useful practice activities. The main improvement needed is not simply adding more topics or increasing the chapter's length.

The chapter should explain more clearly how its main concepts connect to one another. In particular, learners should be able to understand how data is prepared, how a model learns through training, how its performance is evaluated, and how it produces predictions when receiving new inputs.

Adding one complete practical example and improving the explanations of training and optimization would significantly strengthen the learning experience.

The existing examples, activities, and chapter structure should be maintained wherever possible. The goal is to improve the depth and clarity of the material without unnecessarily repeating content from other chapters.

## 8. Final Review Result

Chapter 3 demonstrates good overall quality and provides broad coverage of the fundamental processes and concepts behind artificial intelligence.

The chapter already contains the main learning components expected in Stage 2, including learning objectives, explanations, examples, visuals, practice questions, hands-on activities, and references.

* Connecting the main AI learning processes into one clear sequence.
* Developing the relationship between model training and optimization concepts.
* Adding an integrated practical example.
* Clarifying the differences between training, evaluation, and inference.
* Improving visual explanations and completing learner testing.

The current chapter does not require a complete rewrite. Its foundation is sufficiently strong, but the recommended revisions should be completed before the final Stage 2 submission.
