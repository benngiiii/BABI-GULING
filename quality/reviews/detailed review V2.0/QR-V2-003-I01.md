## 3. Review Findings and Suggested Improvements

### QR-V2-003-I01 — General Review Findings

The review found that Chapter 3 provides a comprehensive and beginner-friendly explanation of how Artificial Intelligence works.

The following positive findings were identified:

**1. Clear Explanation of the AI Workflow**

The chapter introduces the complete AI development process, from defining a problem and collecting data to training, evaluation, deployment, and monitoring.

The bakery analogy makes the workflow easier for beginners to understand.

**2. Strong Explanation of Data and Data Quality**

The chapter explains datasets, features, labels, and different data types. It also introduces training, validation, and test sets, helping students understand why data preparation is important.

**3. Effective Explanation of Algorithms and Models**

The distinction between an algorithm and a model is explained clearly using a familiar recipe-and-cake analogy.

The introduction to classification, regression, and common algorithm families provides useful foundational knowledge.

**4. Practical Explanation of Machine Learning**

The learning loop — predict, measure error, adjust, and repeat — provides a clear explanation of how machine learning models improve.

The gradient descent example makes the learning process easier to follow through numerical calculations.

**5. Good Introduction to Neural Networks and Deep Learning**

The chapter introduces neurons, layers, weights, and deep learning using accessible explanations and diagrams.

These concepts prepare learners for more detailed study of neural network architectures.

**6. Useful Explanation of Modern Language AI**

The explanation of tokens, next-token prediction, attention, pre-training, fine-tuning, and feedback training provides a useful introduction to modern language models.

**7. Strong Model Evaluation Section**

The chapter explains confusion matrices, accuracy, precision, and recall with clear numerical examples.

The discussion of why accuracy alone can be misleading is especially useful for developing critical thinking.

**8. Effective Practical Missions**

Mission 1 allows students to practise finding suitable model settings using house-price data.

Mission 2 helps students calculate and compare model evaluation metrics using a spam-filter example.

**Final Finding:**

Chapter 3 demonstrates strong technical explanations, practical learning support, and suitable beginner accessibility. No blocking quality issues were identified.
