## 3. Review Findings and Suggested Improvements

### QR-V2-009-I01 — Findings Requiring Revision

**Finding 1: Current Progress information needs to be updated**

**Location:** Section 2 — Project Overview / Current Progress

The previous review identified that the Current Progress summary still contained placeholders requiring completion.

As the project has progressed, this section should provide an accurate summary of the current development status rather than leaving incomplete information.

**Required improvement:**
- Replace remaining placeholders with the actual project status.
- Reflect the current Stage 2 progress.
- Make sure the information agrees with the latest Master Task List and Project Plan.

**Finding 2: Learning outcomes require alignment with the updated curriculum**

**Location:** Section 2 — Learning Outcomes

The learning outcomes provide a useful overview of the module. However, the second learning outcome needs to explicitly reflect the three classic approaches to AI.

The updated module structure covers:
- Symbolic AI.
- Connectionist AI.
- Behaviorist AI.

**Required improvement:**

Update Learning Outcome 2 to clearly mention the three approaches and ensure that the wording matches the latest Module Outline.

**Finding 3: Chapter information needs to reflect the latest structure**

**Location:** Section 3 — Chapter Overview

The README provides an overview of the eight chapters, but the chapter descriptions and their connections should be checked against the latest chapter structure.

In particular, the updated Chapter 3 structure includes:
- Section 3.3 — Three Classic Approaches.
- Section 3.4 — Symbolic AI.
- Section 3.5 — Connectionist AI and Big Data.
- Section 3.6 — Behaviorist AI.

**Required improvement:**
- Update the Chapter 3 description to reflect the latest structure.
- Ensure chapter titles and authors match the current files.
- Check that the chapter overview does not conflict with the latest Module Outline.

**Finding 4: Repository structure and folder paths need updating**

**Location:** Section 6 — Repository Structure

The repository has developed as Stage 2 materials have expanded. The README should therefore show the current folder structure rather than relying on an earlier version.

**Required improvement:**
- Update the Stage 2 folder path to the current V2.0 structure.
- Check that the displayed folder hierarchy matches the actual repository.
- Remove outdated folder names or references.
- Ensure that the paths used in navigation instructions point to the correct files.

**Finding 5: Project document navigation requires an update**

**Location:** Sections 5 and 9 — Project Documents and Repository Navigation

The README lists supporting documents and provides navigation instructions. However, these sections need to reflect the latest Stage 2 deliverables.

The current project includes six main Stage 2 deliverable groups:

1. Markdown Content V2.0 ZIP.
2. Study Guide and Test Bank.
3. PPT Slides.
4. Video Tutorials and Video Guide.
5. Project Log and Meeting Summaries.
6. Personal Logs.

**Required improvement:**
- Update the document list to include the latest deliverables.
- Organise the navigation table according to the current repository structure.
- Check that each listed resource has a correct destination.
- Avoid presenting planned or incomplete materials as completed deliverables.

**Finding 6: Stage 2 progress and workflow information need to be revised**

**Location:** Sections 7 and 8 — Project Workflow and Stage 2 Overview

The existing workflow provides a useful explanation of the development process. However, the README should reflect the actual Stage 2 production workflow and the expanded deliverables.

The current workflow follows:

Markdown Content → Study Guide and Test Bank → PPT Slides → Video Tutorials.

Quality review, revision and evidence collection should also be represented in the workflow.

**Required improvement:**
- Update the workflow to reflect the latest production sequence.
- Include the Quality Review and revision process.
- Update the Stage 2 progress information using the latest project records.
- Ensure that the Stage 2 overview does not contain outdated milestones or incomplete placeholders.

**Finding 7: Visual and diagram references require verification**

**Location:** Sections 6 and 8 — Repository Structure and Stage 2 Overview

The README uses visual elements to help readers understand the repository and project schedule.

However, these references should be checked against the latest folder structure and project progress.

**Required improvement:**
- Verify that the diagrams represent the current project structure.
- Update outdated visual information.
- Check that image paths are correct and images display properly.
