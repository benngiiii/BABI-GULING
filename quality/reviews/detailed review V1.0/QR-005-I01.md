## 3. Review Findings and Suggested Improvements

### Finding 1 — Reference Accessibility and Source Verification

**Location:** References and relevant technical explanations
**Priority:** Low
**Status:** Open

**Finding:**

The chapter includes relevant references supporting its explanations of AI bias, privacy, hallucinations, and responsible AI.

However, some claims and regulatory explanations would be easier to verify if readers could access the original sources directly.

In particular, the explanation of the four-fifths rule and the discussion of the EU AI Act would benefit from clear source references.

**Suggested Improvement:**

Add direct links to original publications or official sources where available.

Ensure that the four-fifths rule continues to be described as a screening indicator rather than definitive proof of discrimination.

Use an official source for the EU AI Act so readers can verify the regulatory information.

The existing reference list can be preserved.

**Expected Result:** Readers can easily access and verify the sources supporting important explanations.

### Finding 2 — Markdown Navigation and Figure Presentation

**Location:** Table of Contents and bias diagram
**Priority:** Low
**Status:** Open

**Finding:**

The Table of Contents uses long GitHub URLs to link to sections within the same document.

Although these links may work, they are less convenient to maintain than internal Markdown anchors.

The bias diagram is also presented as a hyperlink rather than an embedded image.

This may reduce the visual clarity of the chapter.

**Suggested Improvement:**

Consider replacing long GitHub URLs with internal Markdown anchors for the Table of Contents.

If the bias diagram is stored in the repository, use standard Markdown image syntax so that it appears directly in the chapter.

Check the rendered GitHub document and exported PDF to confirm that the navigation links and figures display correctly.

**Expected Result:** The chapter has cleaner internal navigation and more consistent figure presentation.
