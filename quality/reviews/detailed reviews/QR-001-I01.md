## 3. Review Findings and Suggested Improvements

**Overall Finding:**

Chapter 1 is well organized and provides a clear introduction to Artificial Intelligence. Most of the content is suitable for beginners, and the worked example and practice questions help explain the concepts.

However, a few minor improvements and one alignment issue were identified during the review.

### QR-001-I01 — Content Clarification and Module Alignment

**Severity:** Medium
**Status:** Open

The following points are recommended for improvement:

**1. Clarify the machine learning explanation (Section 1.3)**

The chapter explains machine learning using examples with correct answers. This is accurate for supervised learning, but not all machine learning approaches require labeled data.

It is recommended to briefly clarify that the example describes supervised learning.

**Suggested addition:**

> This is an example of supervised learning, where a model learns from labeled data. Other machine learning approaches may learn without labeled answers.

**2. Improve the explanation of Question 9 (Section 1.6)**

The calculation and prediction in Question 9 are correct. However, the explanation could clarify that the numerical score is not a probability or a direct measure of confidence.

**Suggested addition:**

> The score is not a probability or a direct measure of confidence. Since the model uses only a small training dataset and simple word counts, its predictions may not always be reliable.

This is a minor improvement and does not affect the correctness of the existing answer.

**3. Check the Table of Contents links**

The Table of Contents currently uses full GitHub URLs.

Although these links may work, internal Markdown links would be easier to maintain if the chapter is moved or merged into another branch.

For example:

`[Learning Outcomes](#learning-outcomes)`

This is an optional improvement as long as the existing links work correctly.

**4. Align the worked example with the Module Outline (Sections 1.3 and 1.5)**

The Module Outline plans a worked example comparing a rule-based program and a learning-based program solving the same task.

The current chapter explains both approaches but only provides a complete worked example for the learning-based spam filter.

To resolve this difference, the team can choose one of the following:

* **Option A:** Add a short rule-based spam filter example so readers can compare both approaches directly.
* **Option B:** Update the Module Outline to match the existing learning-based spam filter example.

Option B may be more practical for Stage 1 because the current example already explains training, inference, and model limitations.

**5. Check image display and sources**

The chapter includes several figures and image links. Please confirm that the images display correctly in the rendered GitHub document.

Some image captions also contain source information marked as "TO BE CONFIRMED." These should be updated when the information is available.

This is a minor documentation check rather than a major content issue.
