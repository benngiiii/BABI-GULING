This review evaluates the Team Project Plan and Master Task List against the official Stage 1 assignment requirements for the course **26-27学期-人工智能与计算科学（全英文）2班**.

The review is based on the uploaded document and the assignment instructions provided. GitHub links, commit histories, and external evidence have not been independently verified during this review.

## 3. Review Findings and Suggested Improvements

### Finding 1 — Missing Individual Learning Needs

**Status:** Minor Revision Required

**Location:** Strengths; Responsibilities Based on Roles

**Issue:**

The document identifies each member's strengths and responsibilities. However, the assignment also requires relevant skills that each member needs to develop.

These learning needs are not explicitly included.

**Suggested Improvement:**

Add a column titled **Skills to Develop** to the team information or strengths table.

Identify one or two relevant learning needs for each member, such as technical writing, GitHub collaboration, presentation skills, or video production.

**Review Result:** Partially Meets Requirements

**Further Revision Required:** Yes

### Finding 2 — Insufficient Content Outline and Scope Boundaries

**Status:** Changes Required

**Location:** Project Purpose; Learning Outcomes; Project Planning Sections

**Issue:**

The document identifies five main chapters:

* Introduction to AI
* Types of AI
* How Artificial Intelligence Works
* Applications of AI
* AI Ethics and Limitations

However, the assignment requires a more specific content outline, including major topics and subtopics.

The document also does not clearly identify which concepts will receive detailed explanations and which will only be introduced briefly.

**Suggested Improvement:**

Add a dedicated **Content Outline and Scope Boundaries** section.

For each chapter, identify the major subtopics and their intended depth.

The team should also clarify any uncertain topics that may require discussion with the lecturer.

**Review Result:** Does Not Fully Meet Requirements

**Further Revision Required:** Yes

### Finding 3 — Learning Resource Plans Need More Detail

**Status:** Minor Revision Required

**Location:** Project Purpose; Deliverable Ownership; Stage 2 Tasks

**Issue:**

The document explains the general purposes of the Study Guide, PPT Slides, and Video Tutorials.

However, the assignment asks for initial plans describing how each resource will be organized and used.

The current descriptions do not sufficiently explain:

* Study Guide structure and learner activities.
* Test Bank organization and self-checking methods.
* Proposed slide diagrams or worked examples.
* Video tutorial topics and demonstrations.

**Suggested Improvement:**

Add a **Planned Learning Resources** section describing each resource's proposed structure, learning activities, and relationship to the shared Markdown content.

**Review Result:** Partially Meets Requirements

**Further Revision Required:** Yes

### Finding 4 — Live Mini Lecture Proposal Is Incomplete

**Status:** Changes Required

**Location:** Deliverable Ownership; Stage 2 Tasks

**Issue:**

The document assigns responsibility for live teaching and includes rehearsal tasks.

However, it does not identify a specific proposed mini-lecture topic or explain its importance.

The assignment also requires an initial teaching approach, including an example, demonstration, or audience activity.

**Suggested Improvement:**

Add a **Live Mini Lecture Proposal** section containing:

* Proposed topic.
* Reason for selecting the topic.
* Main learning objective.
* Proposed explanation or demonstration.
* Audience participation activity.
* Responsible members.

The topic should focus on one manageable question within the AI Overview module.

**Review Result:** Does Not Fully Meet Requirements

**Further Revision Required:** Yes

### Finding 5 — Project Risks and Responses Are Not Explicitly Documented

**Status:** Changes Required

**Location:** Workflow; Rough Plan; Master Task List

**Issue:**

The document includes a workflow and internal deadlines.

However, it does not clearly identify the main project risks and how the team intends to respond.

The assignment specifically requests consideration of risks such as unfamiliar tools, difficult content, uneven workloads, and delayed tasks.

**Suggested Improvement:**

Add a **Risk Management** table containing:

| Risk                  | Possible Impact                    | Planned Response                                   |
| --------------------- | ---------------------------------- | -------------------------------------------------- |
| Unfamiliar tools      | Delays in producing materials      | Provide team support and allow time for practice   |
| Difficult AI concepts | Inaccurate or unclear explanations | Research, peer review, and quality checks          |
| Uneven workload       | Delayed tasks                      | Redistribute tasks when necessary                  |
| Late revisions        | Submission delays                  | Use internal deadlines and track unresolved issues |

**Review Result:** Does Not Fully Meet Requirements

**Further Revision Required:** Yes

### Finding 6 — Task Dependencies Are Not Clearly Recorded

**Status:** Minor Revision Required

**Location:** Master Task List — Stage 1, Stage 2, and Stage 3

**Issue:**

The Master Task List contains task descriptions, responsible members, deliverables, deadlines, statuses, and evidence.

However, task dependencies are not explicitly identified.

For example, the production of PPT Slides depends on sufficiently developed Markdown content, while final submission depends on completing quality reviews and corrections.

**Suggested Improvement:**

Add a **Dependencies** column or identify dependencies in a separate section.

Use task IDs to reference prerequisite tasks where relevant.

**Review Result:** Partially Meets Requirements

**Further Revision Required:** Yes

### Finding 7 — Task Status and Version Inconsistencies

**Status:** Changes Required

**Location:** Master Task List; Stage 1 Submission Report; Quality Review Summary

**Issue:**

Several entries require verification or synchronization:

1. The document header identifies source version **v1.1**, while the Stage 1 Submission Report references the Master Task List as **v1.2**.
2. Task S1-02 remains **In Progress**, although the document also describes a revised Master Task List.
3. Task S1-05 remains **In Progress**, indicating that the revised task list has not completed rechecking.
4. Tasks S1-15 and S1-16 are marked **Not Started** in the provided snapshot.
5. The Submission Report lists the Master Task List review as **Changes Required**, with a recheck pending.

These entries may represent different stages of development, but the document does not clearly reconcile them.

**Suggested Improvement:**

Confirm the latest document version and update all related references.

Verify the actual status of each Stage 1 task and ensure that the submission report reflects the same information.

Do not mark tasks as completed unless their outputs and supporting evidence have been confirmed.

**Review Result:** Inconsistent — Verification Required

**Further Revision Required:** Yes

### Finding 8 — Submission Package Contains Unresolved Items

**Status:** Changes Required

**Location:** Stage 1 Submission Report — Section 10, Submission Package Contents

**Issue:**

The submission package table identifies:

* Readable PDF of learning content — **Not yet produced**.
* Complete ZIP package — **Not yet produced**.
* Submission Report — **Draft**.

Some file locations also remain marked **[TO CONFIRM]**.

Additionally, the reviewer field contains **[TO CONFIRM after review]**.

These entries indicate that the submission package has not been fully finalized in the reviewed snapshot.

**Suggested Improvement:**

Confirm the final submission requirements for each Stage 1 assignment.

Update file locations and statuses to reflect the actual submitted materials.

Remove unresolved placeholders only after the relevant information has been verified.

The Team Project Plan assignment specifically requires one readable Word or PDF document named **TeamName_Stage1_ProjectPlan**, containing the project plan, current task-list snapshot, and repository link.

**Review Result:** Incomplete — Finalization Required

**Further Revision Required:** Yes

### Finding 9 — Formatting and Navigation Issues

**Status:** Minor Revision Required

**Location:** Table of Contents; Deliverable Ownership; Master Task List; Repository Links

**Issue:**

Several formatting and navigation issues are visible in the uploaded document:

* Some Table of Contents entries display Markdown anchor references as plain text.
* The Deliverable Ownership table contains **Master Task Lis** instead of **Master Task List**.
* Some repository links and file paths require cleanup.
* The document combines the Master Task List and Stage 1 Submission Report, but the Table of Contents does not clearly represent the complete combined structure.

These issues reduce the document's readability and navigation quality.

**Suggested Improvement:**

Correct spelling errors, verify hyperlinks, and regenerate the Table of Contents.

Ensure that the final Word or PDF version has readable tables, consistent headings, and working navigation.

**Review Result:** Minor Formatting Issues

**Further Revision Required:** Yes
