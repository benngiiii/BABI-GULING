## 3. Review Findings and Suggested Improvements

**Overall Finding:**

Chapter 3 provides a detailed explanation of how AI systems work, including data preparation, machine learning, neural networks, training, inference, evaluation, and deployment.

The chapter includes useful examples, comparison tables, diagrams, and learning activities. The overall structure is clear and covers the main topics required by the Module Outline.

However, several formatting issues and a few content clarifications should be addressed before the chapter is considered complete.

### QR-003-I01 — Content and Formatting Improvements

**Severity:** Medium
**Status:** Open

The following points are recommended for improvement:

**1. Fix the practice questions and provide explained answers (Section 3.16)**

The practice questions in Section 3.16 are not properly separated in the submitted Markdown.

Several questions appear in one continuous paragraph, making them difficult to read. The answer sections are also not displayed correctly, and readable explanations are missing.

**Suggested Improvement:**

Separate each question clearly and provide an answer with a short explanation.

For example:

**Q1. What is the difference between an algorithm and a model?**

**Answer:** An algorithm is a procedure used to learn from data, while a model is the result of applying that procedure to training data.

Apply the same format consistently to all twelve questions.

**2. Correct the temperature table formatting (Section 3.7)**

The table explaining low and high temperature is combined with the previous paragraph.

As a result, the Markdown table may not display correctly.

**Suggested Improvement:**

Move the table to a separate section with proper Markdown formatting.

**3. Correct the Chapter 2 reference (Section 3.4)**

The chapter states that Chapter 2 covers supervised, unsupervised, and reinforcement learning.

However, Chapter 2 mainly discusses capability-based and functionality-based AI classifications.

**Suggested Improvement:**

Remove or revise the cross-chapter reference so that it accurately reflects the content of Chapter 2.

**4. Clarify the explanation of improving AI without retraining (Section 3.8)**

The section discusses methods for improving AI results without retraining the model.

However, the comparison table also includes fine-tuning and training from scratch, which involve training.

**Suggested Improvement:**

Separate inference-time improvement methods from training-based improvement methods, or clearly explain the difference.

**5. Improve image and diagram presentation**

Several figures are provided as hyperlinks rather than embedded images. Some diagrams also use temporary rendering links.

**Suggested Improvement:**

Check that all figures display correctly in GitHub and in the exported PDF.

Where possible, use Markdown image syntax and store the figures in the repository's assets folder.

**6. Strengthen references for technical explanations**

The chapter includes a Further Reading and Resources section, but direct references supporting some technical explanations are limited.

**Suggested Improvement:**

Add a few relevant references for important concepts such as machine learning, neural networks, transformers, and model evaluation.

A short list of reliable sources is sufficient for this introductory module.
