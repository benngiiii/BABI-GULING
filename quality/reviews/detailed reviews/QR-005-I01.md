## 3. Review Findings and Suggested Improvements

**Overall Finding:**

Chapter 5 provides a clear and comprehensive introduction to AI ethics and limitations. It covers bias, privacy, hallucinations, and responsible AI using practical examples, worked calculations, activities, and answer keys.

The chapter is well structured for beginners and includes relevant references to research, institutional guidance, and real-world cases.

### QR-004-I01 — Reference and Markdown Improvements

**Severity:** Low
**Status:** Open

The following improvements are recommended:

**1. Improve reference accessibility**

The chapter includes relevant references supporting its discussion of AI bias, privacy, hallucinations, and responsible AI. However, some claims and regulatory explanations would be easier to verify if readers could access the original sources directly.

**Suggested Improvement:**

* Add direct links to original publications or official sources where available.
* Ensure that the explanation of the four-fifths rule continues to describe it as a screening indicator rather than definitive proof of discrimination.
* Use an official source for the EU AI Act so readers can check the regulatory information.

The existing reference list provides a useful foundation, so a complete rewrite of the references is unnecessary.

**2. Improve Markdown navigation and figure presentation**

The Table of Contents uses long GitHub URLs for links to sections within the same document. The bias diagram is also provided as a hyperlink rather than an embedded image.

**Suggested Improvement:**

* Consider using internal Markdown anchors for the Table of Contents.
* If the diagram is stored in the repository, use Markdown image syntax so it appears directly in the chapter.
* Check the rendered GitHub page and exported PDF to confirm that navigation links and figures display correctly.

These are minor presentation improvements and do not affect the chapter's overall content quality.
