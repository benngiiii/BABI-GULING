## 3. Review Findings and Suggested Improvements

**Overall Finding:**

Chapter 2 provides a clear and well-organized introduction to different types of Artificial Intelligence. The explanations are appropriate for beginners, and the comparisons help readers understand the differences between existing and hypothetical AI capabilities.

However, a few improvements are recommended to better align the chapter with the Module Outline and strengthen its learning activities.

### QR-002-I01 — Module Alignment and Learning Activity Improvements

**Severity:** Medium
**Status:** Open

The following points are recommended for improvement:

**1. Align the chapter topics with the Module Outline**

The Module Outline lists Narrow AI, General AI, Machine Learning, and Generative AI as the main topics for Chapter 2.

The current chapter focuses mainly on capability-based classification (ANI, AGI, and ASI) and functionality-based classification (Reactive Machines, Limited-Memory AI, Theory-of-Mind AI, and Self-Aware AI).

Although these classifications are relevant, Machine Learning and Generative AI are not sufficiently explained as part of the chapter's overall discussion.

**Suggested Improvement:**

Add a short section explaining how Machine Learning and Generative AI relate to the classification frameworks.

The explanation should clarify that Machine Learning is an approach used to build AI systems, while Generative AI refers to systems designed to generate content.

These concepts should not be presented as categories equivalent to ANI, AGI, or ASI.

Alternatively, the team may update the Module Outline if the current chapter structure better reflects the agreed learning objectives.

**2. Develop the planned classification activity**

The Module Outline includes a planned activity in which learners classify real AI products or systems into different AI types.

The current chapter contains practice questions, but it does not include a dedicated classification exercise involving several real-world AI systems.

**Suggested Improvement:**

Add a short classification activity using familiar AI applications.

For example, learners could classify:

* A spam detection system.
* A video recommendation system.
* A conversational AI assistant.
* A driver-assistance system.

The activity should include an answer key with short explanations.

This would help learners apply the classification concepts rather than only memorize their definitions.

**3. Consider adding a simple visual comparison**

The chapter already includes useful comparison tables for the two classification frameworks.

A simple diagram could further help readers understand how the frameworks differ and why they should not be treated as interchangeable.

This is an optional improvement because the existing tables already communicate the main concepts clearly.
