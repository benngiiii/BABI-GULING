## 3. Review Findings and Suggested Improvements

### QR-002-I01 — Module Alignment: Machine Learning and Generative AI

* **Severity:** Medium
* **Status:** Open
* **Category:** Module Alignment and Completeness

**Finding:**

The Module Outline lists Narrow AI, General AI, Machine Learning, and Generative AI as the main topics for Chapter 2.

The current chapter focuses primarily on two classification frameworks:

1. **Capability-based classification:** Artificial Narrow Intelligence (ANI), Artificial General Intelligence (AGI), and Artificial Superintelligence (ASI).
2. **Functionality-based classification:** Reactive Machines, Limited-Memory AI, Theory-of-Mind AI, and Self-Aware AI.

Although these classifications are relevant, Machine Learning and Generative AI are not sufficiently explained as part of the chapter's overall discussion.

Readers may also misunderstand the relationship between these concepts if they are presented without clarification.

**Suggested Improvement:**

Add a short section explaining how Machine Learning and Generative AI relate to the classification frameworks.

The explanation should clarify that:

* **Machine Learning** is an approach used to develop AI systems that learn patterns from data.
* **Generative AI** refers to AI systems designed to generate content, such as text, images, or audio.
* These concepts describe different aspects of AI and should not be treated as categories equivalent to ANI, AGI, or ASI.

Alternatively, the team may update the Module Outline if the current chapter structure better reflects the agreed learning objectives.

**Acceptance Criteria:**

* Machine Learning and Generative AI are adequately explained or the Module Outline is updated to reflect the agreed chapter scope.
* Their relationship with capability-based and functionality-based classifications is clear.
* The chapter does not incorrectly present these concepts as equivalent categories.
* The explanations remain suitable for beginners.

### QR-002-I02 — Classification Activity Using Real-World AI Systems

* **Severity:** Medium
* **Status:** Open
* **Category:** Learning Activities and Worked Examples

**Finding:**

The Module Outline includes a planned activity in which learners classify real AI products or systems into different AI types.

The current chapter contains ten practice questions with explained answers. However, it does not include a dedicated classification exercise involving several familiar real-world AI applications.

A practical classification activity would help readers apply the concepts instead of only memorizing definitions.

**Suggested Improvement:**

Add a short classification activity using familiar AI applications, such as:

1. A spam detection system.
2. A video recommendation system.
3. A conversational AI assistant.
4. A driver-assistance system.

Learners should identify appropriate classifications and briefly explain their reasoning.

The activity should include an answer key with short explanations.

Where relevant, the explanations should acknowledge that a system's classification depends on its actual design and functionality.

**Acceptance Criteria:**

* A dedicated classification activity is included.
* The activity uses several familiar AI applications.
* Learners are asked to explain their classifications.
* An answer key with explanations is provided.
* The classifications are consistent with the chapter's explanations.

### QR-002-I03 — Visual Comparison of AI Classification Frameworks

* **Severity:** Low
* **Status:** Optional Improvement
* **Category:** Visual Presentation and Clarity

**Finding:**

The chapter already includes useful comparison tables for the capability-based and functionality-based classification frameworks.

These tables help readers understand the differences between the two approaches.

However, a simple visual diagram could make the relationships between the frameworks easier to understand, particularly for beginners who are unfamiliar with AI terminology.

This is an optional improvement because the existing tables already communicate the main concepts clearly.

**Suggested Improvement:**

Consider adding a simple diagram showing that:

* Capability-based classification describes the scope of an AI system's intelligence.
* Functionality-based classification describes how an AI system operates or uses information.
* Machine Learning and Generative AI describe other aspects of AI systems rather than additional levels in the same classification hierarchy.

The diagram should be simple and should not imply that all frameworks form one standardized taxonomy.

**Acceptance Criteria:**

* If a diagram is added, it accurately represents the relationships between the frameworks.
* The diagram is readable in the intended document format.
* The existing comparison tables remain understandable.
* No diagram is required if the team decides the existing tables are sufficient.
