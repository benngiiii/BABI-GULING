## 1. Content Accuracy
- [ ] Definitions are correct.
- [ ] Technical explanations are accurate.
- [ ] Examples are relevant and correct.

## 2. Learning Quality
- [ ] Explanations are understandable for beginners.
- [ ] Important terminology is defined.
- [ ] Learning objectives are addressed.

## 3. Examples and Activities
- [ ] A worked example is provided.
- [ ] A learner activity is included.
- [ ] Answers are explained.

## 4. References
- [ ] Sources are credible.
- [ ] Important claims are supported.
- [ ] Borrowed materials are acknowledged.

## 5. Markdown Quality
- [ ] Formatting is correct.
- [ ] Images display correctly.
- [ ] Links work properly.
