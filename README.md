## 2. Purpose, Learners and Goals

**Purpose.** Many students use AI tools every day without knowing how they work. This project teaches the AI Overview module to complete beginners through one shared Markdown content base, turned into a Study Guide with Test Bank, a class slide deck and six video tutorials.

**Intended learners.** Beginners with no background in AI or programming. Learners need basic computer use, school arithmetic (fractions and percentages) and English at the level of this page. Every technical term is explained in plain words before its definition.

**Learning goals.** After the module, learners should be able to:

1. Explain what AI is and how it differs from traditional programming.
2. Classify AI by capability, functionality, learning method and output.
3. Describe the AI workflow, compare supervised, unsupervised and reinforcement learning, and evaluate a model with simple measures.
4. Explain symbolic, connectionist and behaviorist AI, and give an example of each.
5. Identify real-world applications of AI and the human oversight they need.
6. Recognise limitations and ethical concerns, including bias, privacy, transparency, hallucination, AI agents and regulation.

## 6. How to Open and Use the Materials

| To… | Do this |
| --- | ------- |
| Read the content | Open any `.md` file on GitHub, or in VS Code with Markdown preview (`Ctrl+Shift+V`). Keep each chapter's `assets/` folder next to its `.md` file so the images display. |
| Rebuild the combined file | From the repository root: `python3 tools/build_final_content.py` (Python 3, no extra packages) |
| Make a PDF | Open `Main/final_Content.md` in VS Code with a Markdown-to-PDF extension, or use `pandoc Main/final_Content.md -o final.pdf` (pandoc and a PDF engine required). The submitted PDF was printed from the same file. |
| Do the activities | Pen, paper and a calculator. Platform activities (ELIZA, Machine Learning for Kids, SWISH Prolog, TensorFlow Playground) are free websites; each has a paper version in the Study Guide if the site is unavailable. |
| Play the quiz game | Open <https://babigulingcsai.netlify.app> in any browser. It works offline after the first load. |

## 8. Known Limitations

- **Six videos for eight chapters.** Chapters 4, 5 and 6 share Video 04 (*Three Schools of AI*), so those chapters get less video time than Chapters 1–3. The Resource Mapping and the Video Guide give start times for each part.
- **The Test Bank samples each chapter.** It has 3 True/False, 3 Multiple Choice and 1 Open-ended question per chapter; it does not test every subsection. Section 8.6 (AI agents, new in V3.0) is tested by TF-23.
- **Two visual themes.** The Study Guide uses the "Rebuild Bit" metro theme and the slides and videos use "Babi Guling's Kitchen". A shared "BABI GULING · AI Overview" label links them, but the themes were not merged.
- **Online activities depend on third-party websites.** Paper versions are provided for each.
- **Learner testing was small.** Materials were tested by team members, classmates in peer review and one external learner (quiz game). We have no evidence of learning gains from a larger group.
- **Videos are not stored on GitHub** because of their size; they are submitted on Lexue.
