## 3. GitHub harus di-download jadi ZIP?

**Iya. Kalian perlu mempertahankan repository GitHub online dan menyiapkan ZIP sebagai paket submission.**

Jadi bukan memilih salah satu.

### Cara download GitHub menjadi ZIP

1. Buka repository `BABI-GULING`.
2. Pilih branch `AI-Overview`.
3. Klik tombol hijau **Code**.
4. Pilih **Download ZIP**.
5. Extract ZIP tersebut.
6. Periksa apakah semua folder dan file yang diperlukan sudah masuk.
7. Tambahkan dokumen submission yang diperlukan jika belum ada.
8. Compress kembali menjadi ZIP dengan nama yang sesuai instruksi.

**Nama ZIP:**

`Babi_Guling_Stage1_GitHub_Markdown_V1.zip`

Nama ini mengikuti pola yang sebelumnya tercantum dalam instruksi tugas:

`TeamName_Stage1_GitHub_Markdown_V1.zip`

Gunakan nama tersebut untuk ZIP final, bukan nama otomatis dari GitHub.

### Contoh isi ZIP

```text
Babi_Guling_Stage1_GitHub_Markdown_V1.zip
│
├── Main/
│   ├── README.md
│   ├── project-plan.md
│   ├── master-task-list.md
│   ├── module-outline.md
│   │

│       └── v1.0/

│           ├── chapter-2-types-of-artificial-intelligence/
│           ├── chapter-3-how-artificial-intelligence-works/
│           ├── chapter-4-applications-of-ai/
│           └── chapter-5-ai-ethics-and-limitations/
│
├── quality/
│   └── reviews/
│       ├── quality-standards.md
│       ├── review-register.md
│       ├── final-submission-audit.md
│       └── detailed reviews/
```

Ini **contoh susunan paket**, bukan berarti lu harus mengubah struktur GitHub yang sudah ada. Folder `assets/`, misalnya, hanya diperlukan jika gambar atau aset memang disimpan di sana.

Pastikan ZIP memuat gambar yang dipakai dalam Markdown. Jangan sampai file `.md` ada, tetapi gambarnya hilang.
